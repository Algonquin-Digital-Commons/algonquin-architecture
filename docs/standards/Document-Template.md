## Instructions

1. Choose exactly one document type from PSDC-DOC-001.
2. Replace the control block with a durable owner, accountable maintainer,
   review date, and governing ADRs.
3. State purpose, scope, exclusions, boundaries, dependencies, and decisions in
   the vocabulary of the subject; do not copy generic text without adapting it.
4. Define interfaces, state/data handling, security/privacy, deployment,
   capacity, failure/recovery, testing, alternatives, and binary acceptance
   evidence whenever the selected type requires them.
5. Link the authoritative contracts, ADRs, runbooks, upstream provenance, and
   institution deployment profile. Run both documentation tests before review.
